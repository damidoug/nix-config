A typed host.* schema drives three real machines — one home-manager profile runs everywhere

NixOS + nix-darwin + home-manager, managed with Jujutsu. Every machine's hardware, environment, and tooling is one validated schema; every module is auto-injected, never hand-curated per host.

Architecture

Four directories, each with one job

hosts/ holds machine identity. modules/ holds what that identity gets turned into. lib/ holds the builder that connects them. homes/ holds the user environment, shared by real hosts and standalone machines alike. 

hosts/     pc · pangolin · mac — one directory per real machine
homes/     home-manager profiles — shared by hosts and standalone machines
modules/   the host.* module tree every host is built from
lib/       hosts/ + homes/*/machines/ → real flake outputs
docs/      you are here

Pipeline

From one data file to a running system

1 hosts/<name>/default.nix returns plain data + a module — validated by lib/hostSchema.nix before anything builds
2 lib/mkConfigurations.nix picks nixosSystem / darwinSystem, injects modules/host unconditionally
3 Topic modules under modules/host/<topic>/ read typed host.* fields — no host hand-imports any of it
4 homes/default.nix + homes/<user>/ load the same way for a real host or a standalone homeConfigurations machine
